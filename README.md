# Quiz App

Полноценный сайт-викторина с тёмной темой, похожий на checkbio.web.app.

## Структура проекта

```
quiz-app/
├── backend/
│   └── server.js          ← Node.js + Express сервер (API)
├── frontend/
│   ├── index.html         ← Главная страница
│   ├── css/
│   │   └── style.css      ← Все стили
│   └── js/
│       └── app.js         ← Вся логика (JS)
├── data/
│   └── questions.json     ← ВСЕ ВОПРОСЫ ХРАНЯТСЯ ЗДЕСЬ
├── package.json
└── README.md
```

## Быстрый старт

### 1. Установить Node.js
Скачать с https://nodejs.org (версия 18+)

### 2. Установить зависимости
Открыть терминал в папке `quiz-app` и выполнить:
```bash
npm install
```

### 3. Запустить сервер
```bash
npm start
```

### 4. Открыть сайт
Перейти в браузере по адресу: **http://localhost:3001**

## Как добавить свои вопросы

Открой файл `data/questions.json`. Он выглядит вот так:

```json
{
  "topics": [
    {
      "id": "topic1",
      "title": "Название темы",
      "icon": "📡",
      "lecture": "Lecture 1",
      "questions": [
        {
          "id": 1,
          "question": "Текст вопроса?",
          "options": [
            "Правильный ответ",
            "Неправильный ответ",
            "Неправильный ответ",
            "Неправильный ответ"
          ],
          "answer": 0,
          "slide": 4,
          "reference": "Module 14",
          "explanation": "Объяснение почему ответ правильный."
        }
      ]
    }
  ]
}
```

### Поля:
| Поле | Описание |
|------|----------|
| `id` | Уникальный ID темы (любая строка) |
| `title` | Название темы (отображается на карточке) |
| `icon` | Emoji иконка |
| `lecture` | Название лекции (для вкладок-фильтров) |
| `question` | Текст вопроса |
| `options` | Массив из 2-4 вариантов ответов |
| `answer` | Индекс правильного ответа (0 = первый вариант) |
| `slide` | Номер слайда (необязательно) |
| `reference` | Ссылка (необязательно) |
| `explanation` | Объяснение после ответа |

## API эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/topics` | Все темы (список) |
| GET | `/api/topics/:id` | Тема с вопросами |
| POST | `/api/topics` | Добавить тему |
| PUT | `/api/topics/:id` | Обновить тему |
| DELETE | `/api/topics/:id` | Удалить тему |
